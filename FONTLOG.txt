FONTLOG for Ricing
==================

Ricing is a variable font with a single axis: wght (100-900).

Every letter is composed of rice grain tapered ovals.
At wght 900, the grains converge into recognizable letter shapes.
At wght 100, the grains scatter apart, breaking the forms into
abstract rice-like fragments.

Design: Michael Seh
Foundry: Michael's Fonts

Format
------
- Ricing-VF.otf  — OpenType variable font (TrueType outlines)
- Ricing-VF.woff2 — WOFF2-compressed variable font for web use
- static/*.ttf — 9 static instances (Thin through Black)

Technical Details
-----------------
- UPM: 1000
- Axes: wght 100-900 (two masters: Light at 100, Bold at 900)
- Glyphs: 96 base glyphs + 12 contextual alternates (108 total)
  - A-Z uppercase
  - a-z lowercase
  - 0-9 digits (tabular width)
  - 32 symbols: ` ~ ! @ # $ % ^ & * ( ) - _ = + [ ] { } \ | ; : ' " , . < > / ?
- Features: GSUB calt (contextual alternates), GPOS kern (kerning)
- All grains uniform size at each weight
